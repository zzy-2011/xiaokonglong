# 🦖 小恐龙跑酷 (Dino Runner)

一个用纯 HTML5 Canvas 实现的「恐龙跑酷」小游戏，灵感来自 Chrome 离线小恐龙。
**无需任何外部图片或音频资源**，全部用代码绘制，开箱即玩。

## 玩法
- **空格 / ↑ / 点击屏幕** —— 跳跃
- **↓** —— 下蹲（躲开翼龙）
- **P** —— 暂停 / 继续

躲避仙人掌与翼龙，分数越高速度越快。每 700 分切换一次昼夜。最高分记录保存在浏览器 `localStorage`。

## 特性
- 纯 Canvas 绘制的小恐龙、仙人掌、翼龙、云朵与星空
- 随分数动态加速 + 昼夜循环
- 桌面键盘 + 移动端触屏（点按跳跃、按住下半屏下蹲）
- WebAudio 生成的跳跃 / 失败音效（无音频文件）
- 最高分本地保存

## 运行
直接用浏览器打开 `index.html` 即可，或启动一个本地静态服务器：

```bash
# 任选其一
python -m http.server 8000
# 然后访问 http://localhost:8000
```
